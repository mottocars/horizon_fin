Horizon Finanças

API Horizon

Consulte os certificados digitais e as notas fiscais (NF-e e NFS-e) que o Horizon captura na Receita e nas prefeituras, saiba quais já foram vinculadas ao contas a pagar e inative as que não devem ser lançadas.

Endereço base
Autenticação
Chave → token Bearer de 15 min
Formato
JSON, UTF-8
Datas e horas
Horário de Brasília (-03:00)

Início rápido

  1. 1

    Gere uma chave no Horizon Finanças, em Integrações › API Horizon › Nova chave. É preciso ter acesso à tela Espião NFe / NFSe.

    A chave aparece uma vez só: guarde num cofre de senhas.

  2. 2

    Troque a chave por um token. Ele vale 15 minutos.

  3. 3

    Consulte com o token no cabeçalho Authorization. Comece pelos certificados e depois liste as notas deles.

Autenticação

Chave de API hzn_…

  • Gerada em Integrações › API Horizon, com validade de 90 dias, 180 dias ou 1 ano.
  • Presa a um usuário (age com as permissões dele) e a uma empresa (só enxerga os dados dela).
  • Só de leitura, ou leitura + inativar notas.
  • Enviada só em POST /auth/token, no cabeçalho X-Api-Key.

Token hzt_…

  • Vale 15 minutos. Reaproveite até expirar.
  • Enviado em todas as outras rotas: Authorization: Bearer <token>.
  • Expirou (401 TOKEN_EXPIRADO)? Gere outro com a chave.
  • Serve só para esta API: não abre nenhuma tela do Horizon.

Permissões conferidas a cada chamada. O dono da chave precisa estar ativo, com acesso à tela Espião NFe / NFSe e à empresa da chave. Se perder qualquer um, a API responde 403 SEM_PERMISSAO na hora. Revogar a chave invalida também os tokens já gerados com ela.

Testar nesta página

Cole sua chave e use o botão Executar de cada endpoint. A cada execução a página gera um token novo e faz a chamada com ele — os dados são reais.

A chave fica só na memória desta aba: não é gravada e some ao recarregar a página.

Nota fiscal

Objeto devolvido pela listagem, pela consulta de uma nota e pela inativação.

statusInterno

Mesmas abas do Acervo NF-e / NFS-e. Quando mais de um vale, prevalece nesta ordem: inativada, cancelada, vinculada, pendente.

Consulta incremental

Para não baixar tudo a cada rodada, guarde o momento em que a consulta começou e envie esse valor em atualizadoDesde na próxima.

dataAtualizacao muda quando a nota:

  • é capturada;
  • é inativada ou reativada;
  • é vinculada ou desvinculada do contas a pagar;
  • recebe um evento fiscal (cancelamento, CT-e, comprovante de entrega…).

Mantenha o período de emissão cobrindo as notas que você acompanha (até 366 dias).

Erros

Todo erro vem com o status HTTP e um corpo no mesmo formato. Trate pelo codigo; a mensagem é para pessoas e pode mudar.

Limites

Consultas, XML e inativação60 por minuto, por chave

Passou do limite: 429 LIMITE_EXCEDIDO com o cabeçalho Retry-After (segundos até liberar). Toda resposta traz RateLimit e RateLimit-Policy com o saldo restante.

Segurança

  • Guarde a chave num cofre de senhas ou variável de ambiente do servidor. Nunca em código-fonte, repositório, aplicativo ou página web.
  • Use uma chave por sistema, só com a permissão necessária. Inativar notas só quando o fluxo exigir.
  • A chave só trafega em POST /auth/token; nas demais chamadas vai só o token, que expira em 15 minutos.
  • Sempre HTTPS. O Horizon guarda apenas o hash da chave e do token.
  • Vazou? Revogue em Integrações › API Horizon: a chave e todos os tokens dela param na hora.
  • Toda chamada fica registrada (quando, rota, status, IP) e aparece em Chamadas, na tela da chave.
